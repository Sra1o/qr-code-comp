## My process

I started off going step by step, getting the individual elements formatted, then bringing them all together.

### Built with

- Semantic HTML5 markup
- CSS custom properties (variables)
- Flexbox
- Google Fonts (Outfit)
- Mobile-first workflow

### What I learned

Through building this project, I reinforced my understanding of:

- Structuring HTML semantically for basic card components.
- Using CSS variables for consistent color scheming.
- Applying `box-shadow` to create depth and elevate the card off the background.
- Centering elements on the page using margins and basic layouts.

Here is a snippet of the CSS variables used for easy color management:

```css
:root {
    --light-gray: hsl(212, 45%, 89%);
    --gray: hsl(216, 15%, 48%);
    --dark-gray: hsl(218, 44%, 22%);
}
```

## How to use

To view this project locally:

1. Clone the repository to your local machine.
2. Ensure you have the `images` folder containing `image-qr-code.png` in the same directory as your `index.html`.
3. Open `index.html` in your web browser.
